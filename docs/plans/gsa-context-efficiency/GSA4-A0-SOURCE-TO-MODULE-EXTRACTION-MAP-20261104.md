**Therefore A2 selection can initially be an explicit source-reference/Skill suggestion recipe from verified actual records; generalized dynamic Skill injection is a separately tested post-A0 product change, not an assumed existing feature.** Role ≠ Work Position; unknown approval/Task/criteria must READ_MORE or ASK/STOP, not shortcut permission.

5. Re-run all pinned tests/negative mutations on **each commit SHA**, including `deno check`, with actual CI evidence if available. Keep integration `selftest.ts`, root request-bound validator, Auth/HTTP/registration in composition until parity proof.
6. Only after actual code parity, implement A1 locator and A2 logical context pointers (and A3 repair route). Never claim source file split alone reduces model-delivered Harness bytes.
