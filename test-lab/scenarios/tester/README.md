# Tester capability scenarios

This folder holds scenarios that exercise Tester as an independent capability-testing agent.

Tester is expected to turn high-level unknowns into an empirical test plan, specify the evidence it needs, and later verify the produced UI/design through the available UI-testing surface. Relevant operations may include flow traversal, screen/state switching, browser interaction, snapshots, responsive checks, artifact read-back, and evidence packaging.

Detailed test cases belong to Tester when the experiment runs; they are not pre-authored by Planner. Results remain Lab evidence only until a later reviewed workflow explicitly promotes any contract.
