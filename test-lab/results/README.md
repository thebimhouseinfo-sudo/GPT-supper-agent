# Results

Store only small Markdown/JSON manifests that summarize empirical Test Lab runs.

A result should point back to the scenario and target revision, record the observed outcome and limitations, and reference the evidence used. Keep UI Coder capability evidence separate from Tester capability evidence.

Screenshots and other binary/private evidence stay outside Git. When Human review is required, include **direct user-openable links/paths** to the representative screenshots/artifacts in the manifest so the reviewer does not have to locate them manually.

Test Lab results are supporting empirical evidence only. They are not production Verification and do not mutate or satisfy GSA Job/Run lifecycle gates.
